Image Drag & Drop Widget

Modern drag-and-drop image upload for any Odoo field

Replace the default image upload experience with a beautiful, intuitive drag-and-drop zone. Works on any Binary or Image field in any model — products, contacts, projects, custom modules, anywhere.

Features

Drag & Drop

Drop image files directly onto the field. Visual feedback with Odoo-purple highlight on drag hover.

Click to Browse

Click the drop zone or existing image to open a file picker. Standard image file types accepted.

Smart Preview

Shows current image with replacement overlay. Empty state displays an inviting upload zone.

Usage

Add the widget to any Binary or Image field in your XML view:

<field name="image_1920" widget="image_dropzone"/>

Force the empty drop zone to always show (useful beside a preview):

<field name="image_1920" widget="image_dropzone"
       options='{"always_dropzone": true}'/>

Two Display Modes

Empty State

Dashed border with cloud upload icon and clear call-to-action text. Hover highlights the border in Odoo purple.

Image Loaded

Shows the current image with a semi-transparent overlay bar at the bottom: “Click image or drag new image to replace”. Drag hover outlines the image in purple.

Technical Details

  • Widget name: image_dropzone
  • Supported field types: Binary, Image
  • Dependencies: web (only)
